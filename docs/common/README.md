## 如何补充新规则

1. 在本目录新增 `02-xxx.md`、`03-xxx.md` …（序号递增，便于检索）。
2. 若脚本要用：在 `utils/` 增加或扩展对应模块，并在该 md 里写明「代码入口」。
3. 在本 README 表格补一行。
4. 各需求文档（`docs/4834`、`docs/4869` …）只做**链接引用**，不要再抄一份容易过时的全文。
